# Practice-javascript-html-css
exemples / Rock-paper-scissors game
This project is a Rock-Paper-Scissors game developed with JavaScript, HTML, and CSS. It allows users to play against the computer by selecting rock, paper, or scissors, while the computer randomly generates its choice. The application keeps track of the score and displays the result of each round in a clear and interactive interface. The main objective of this project is to practice core JavaScript concepts such as DOM manipulation, event handling, conditional logic, and random number generation. Additionally, it demonstrates the use of HTML and CSS to create a visually appealing and responsive user interface. This project is designed in a learning and academic context, aiming to strengthen front-end development skills and the ability to implement interactive web applications.
